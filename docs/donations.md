# Support AI Toolbox

You can support Alexei Yarilovets and the development of AI Toolbox through [GitHub Sponsors](https://github.com/sponsors/zalexo) or [Buy Me a Coffee](https://buymeacoffee.com/alexeyarilovets).

## GitHub Sponsors

Choose a one-time donation or a monthly sponsorship and select an amount on the sponsor page. GitHub requires you to sign in to sponsor.

## Buy Me a Coffee

Open the [Buy Me a Coffee page](https://buymeacoffee.com/alexeyarilovets) and choose how to support.

## Terms

Donations are optional and are not a condition of using these materials under MIT. A donation does not promise delivery deadlines or individual support.

## Repository funding links

The repository's `.github/FUNDING.yml` lists the GitHub Sponsors account `zalexo` and the Buy Me a Coffee page `alexeyarilovets`. The README links to both.

If the repository's **Sponsor** button is hidden, enable **Settings → General → Features → Sponsorships**. See [GitHub's funding configuration documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).
